# PRD-010 - Sistema de Autenticação e Autorização

## Objetivo

Implementar o sistema completo de autenticação e autorização da plataforma, permitindo o acesso seguro ao painel administrativo e à área do cliente.

O sistema deverá suportar diferentes perfis de usuários e servir como base para todos os módulos protegidos do e-commerce.

---

# Segurança

* Senhas criptografadas com Bcrypt.
* JWT curto (15 minutos).
* Refresh Token longo (7 dias).
* Rate Limit no login.
* Proteção contra força bruta.
* Bloqueio temporário após múltiplas tentativas.
* Sanitização das entradas.
* Nunca retornar informações sensíveis.
* Logout invalida Refresh Token.
